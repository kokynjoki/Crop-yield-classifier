# Crop-yield-classifier
A machine learning project that classifies crop yield into Low, Moderate, and High categories using agricultural and environmental features.

# Overview

Agricultural productivity is influenced by multiple factors, including soil conditions, environmental characteristics, and nutrient availability. Understanding these factors can help support more informed agricultural decision-making.

This project uses machine learning to classify crop yield into three categories: Low, Moderate, and High Yield. The model learns patterns from agricultural data to predict the yield category based on selected input features.

# Problem Statement

How can machine learning be used to classify crop yield based on agricultural and environmental features?

# Objectives
Prepare and explore agricultural data for machine learning.

Identify features associated with crop yield categories.

Develop a classification model to predict yield categories.

Examine feature importance to understand which variables contribute most to predictions.
Methodology

The project follows these main steps:

Data Preparation: Prepare the dataset and select relevant features for modelling.

Target Engineering: Categorize crop yield into Low, Moderate, and High groups using quantile-based binning.

Model Development: Train a machine learning classification model using the prepared dataset.

Model Evaluation: Assess the model's predictive performance using appropriate classification metrics.

Feature Analysis: Examine feature importance to identify the variables contributing most to the model's predictions.
